# 语音助理系统架构与技术排障指南

## 1. 客户端架构概览
- **框架**：Electron 绿色免安装桌面客户端，架构分离为 Main Process（主进程）与 Renderer Process（渲染进程）。
- **音频采集与流转**：通过标准 Web Audio API / AudioWorklet 采集 24kHz / 16kHz PCM16 单声道音频，通过实时 WebSocket 全双工长连接发送至云端。
- **音频播放与打断（Barge-in）**：本地维护高精度播放队列与播放基准指针，当检测到语音开始（`speech_started`）时，立即清空本地待播放音频缓冲，实现零延迟打断。

## 2. Microsoft Foundry 云端直连架构
- **身份认证机制**：基于 Microsoft Entra ID（Azure AD）客户端凭据流（Client Credentials Grant），以 Service Principal（应用名称：`Lilith-VoiceAssistant`）凭据自动获取并动态续期 Bearer Token。
- **项目与智能体路由**：
  - 项目资源：`karas-1-resource`
  - 项目名称：`karas-1`
  - 智能体：`lilith`
  - 核心协议：Azure Voice Live Sessions / GPT-Realtime 协议。
- **知识与记忆整合**：
  - 知识库依托 Azure AI Search（Foundry IQ）索引，支持多模态混合检索（向量 + 语义全文检索）。
  - 记忆库依托 Foundry Memory Store，自动保留历史会话关键要素与用户偏好。

## 3. 常见故障自愈与排障流程
- **401 Unauthorized**：检查 Client Secret 是否过期，重新发起 OAuth2 令牌请求。
- **403 Forbidden**：确认该 Service Principal 在对应 Resource Group 和 Cognitive Services Account 上具备 `Azure AI Developer` 与 `Foundry Agent Consumer` 角色权限。
- **WebSocket 1006 / TLS 异常**：检查系统网络代理设置，确认是否放行 `*.services.ai.azure.com` 域名。
